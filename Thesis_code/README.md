# Code for thesis: Optimal growth strategies in microbial resource allocation models

This repository contains the Python code used to generate the numerical results and figures in my thesis.

## Contents

- `scripts/two_regime_numerical_search.py`: simulations for the step-function model
- `scripts/phase_transition_three_models.py`: simulations for the 3 smooth models
- `scripts/phase_qz_space_three_models.py`: code for plot of optimal strategies on the q-z plane
- `scripts/phase_transition_summary_plots.py`: code for summary of phase transitions found

Python version used: 3.11
